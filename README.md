# Copiloto Financeiro

Plataforma de organização financeira pessoal com IA, feita como projeto final da disciplina de IA Generativa (Instituto Mauá de Tecnologia, 2026).

**Abrir:** https://lucascmazza24-bit.github.io/copiloto-financeiro/

- A página faz todas as contas no seu navegador. Os dados ficam só no seu aparelho; não existe servidor nem login.
- O chat com IA (Gemini) é opcional e só recebe o texto que você decide colar, sem CPF, conta ou senha.
- Simulações de investimento são educativas. Não é recomendação de investimento.
- Os exemplos (Ana, Bruno e Carla) são pessoas fictícias.

Autor: Lucas Cardoso Mazza.
